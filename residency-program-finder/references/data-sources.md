# Data sources — what each gives you, and how much to trust it

Use aggregators to *find* candidates and read signal/score data quickly; use the **program website** to *confirm* the facts that decide an application. Ranked by authority for the things that matter:

| Source | Best for | Trust for composition / visa |
|---|---|---|
| **Program's own website** (roster, eligibility/FAQ, fellowships) | Current residents + their medical schools, visa sponsorship (verbatim), on-site fellowships, program type | **Authoritative.** Always verify here. |
| **Residency Explorer** (residencyexplorer.org, AAMC login) | Interview rate by applicant type, **Gold/Silver signal effect**, Step-2 invited ranges, match data | Great for signal/score data. **Visa & composition: verify on site** (can be wrong/stale). |
| **residencyadvisor.com** | Per-program **school breakdown**, non-US IMG %, visa flags | Useful when a site hides schools. Aggregator estimate — **label as such.** |
| **residencymatch.ai / residencyprogramslist.com** | Per-program **% IMG** and visa, filterable by state | Quick candidate discovery. "% IMG" ≠ "% non-US IMG." Verify. |
| **FREIDA** (freida.ama-assn.org, AMA) | Official program facts, ACGME IDs, some visa/eligibility | Official but sometimes coarse; confirm current-year specifics. |
| **Doximity Residency Navigator** | Reputation, research output, program size | Reputation only; not composition/visa. |
| **NRMP** (Match data, Program Results) | Historical fill by applicant type | Context, not per-program admissions detail. |

## Definitions to keep straight

- **IMG** = international medical graduate. **US-IMG** = US citizen who trained abroad. **Non-US IMG** = non-citizen who trained abroad — the group that needs visa sponsorship. "IMG-friendly" for a visa-requiring applicant should mean **non-US IMG-friendly** (a good working threshold is **>20% non-US IMG residents**).
- **"% IMG"** on aggregators usually blends US-IMG + non-US IMG (and sometimes DOs). Don't quote it as the applicant's odds; find the **non-US IMG** share.
- **Interview rate** (Residency Explorer) = fraction of applicants of a type who were *invited to interview* → attainability per application. Different from **resident composition** (who's actually in the program), which you get from the roster.

## A note on freshness

Rosters, visa policies, and signal counts change every cycle. Prefer current-year pages; treat GME-policy PDFs by their revision date; and look up the **current** program-signal count for the specialty rather than trusting a remembered number.
